# 开挂面板（本地代打）

给你自己的联机贪吃蛇写的小工具：面板里填上账号，AI 替你进房、替你走，你只管在旁边看分数涨。

## 启动

**方式一（推荐）**：双击 `start.command`，浏览器会自动打开 <http://127.0.0.1:8787>。

第一次双击如果提示「无法打开，因为它来自身份不明的开发者」，右键 → 打开，或执行一次：

```sh
chmod +x start.command
```

**方式二**：命令行

```sh
cd cheat-app
node server.js
# 然后打开 http://127.0.0.1:8787
```

只需要 Node 18+（本机是 22），没有第三方依赖。

## 面板字段

| 字段 | 说明 |
| --- | --- |
| 服务器地址 | 默认 `https://snake-online.up.railway.app`，也可以填 `http://localhost:8180` 连本地服 |
| 账号 / 密码 | 你自己的账号。只在内存里用一次，不发往别处，不写文件 |
| 进房方式 | 自己建房（默认，不去打扰别人）/ 进指定房间 / 进人最多的空房间 |
| 房间名 / ID | 只在「进指定房间」时用，名字和 ID 都认 |
| 速度 | 毫秒/拍，0 表示用房间默认；填 50 就是最快那种 |

## 它怎么走位

内核在 `engine.js`，来自仓库里的 `bot/snake-bot.js` v3：

1. 多源 BFS 算每格到最近苹果的步数，优先吃最近的
2. 走完这步还能不能顺着空位摸到自己的尾巴——能摸到就没把自己关死
3. 别人蛇头所在格和四周一圈都算危险格（头对头是两条一起死）
4. 实在没安全路，退一步选空地最多的方向

所以它基本不吃亏：抢食积极、自己绕死的概率很低、也不会去跟人迎头对撞。

## 注意

- **同一个账号别同时开两个**。浏览器里那局还开着，代打进来会抢同一个名字，互相顶。
- 默认只自己建房，别选「进人最多的房间」去屠别人的局，那没意思也容易挨骂。
- 面板只监听 `127.0.0.1`，局域网里别人访问不到。
- 它只看当前这一帧，不预测你下一步，所以遇到会围的真人高手（噩梦派派那种）还是会被挤死。
