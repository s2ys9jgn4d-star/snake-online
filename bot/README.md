# bot/ —— 两个电脑对手

| 文件 | 作用 |
| --- | --- |
| `../ai.js` | 豆包：规则型，只看一步 + 数空地，故意留了犯错概率，好陪小朋友玩 |
| `qagent.js` | 派派：把《训练贪吃蛇AI死了1891次》里的 Q 学习账本搬过来了（状态编码、训练、上场决策都在这里） |
| `qtable.json` | 训练好的账本（约 7 KB，可以重训覆盖） |
| `train-q.js` | 训练脚本：`node bot/train-q.js 1200 eval` |
| `itest.js` | 集成测试：起一个临时服务器 + 登录 + 开单人房，看机器人真的会吃 |
| `snake-bot.js` | 早期写的“代打”脚本，几乎不会死，和上面两个不是一个用途 |

## 派派是怎么想的

- 它的“脑子”是一个字典：`账本[看到的情况] = [直走值几分, 左转值几分, 右转值几分]`
- 看到的情况只有四样东西：三个方向撞不撞、自己朝哪、最近的苹果在哪个方向、三个方向落脚后还够不够转身
- 训练是空棋盘单蛇，奖励只有「吃到 +10 / 撞死 -10」，和公开课视频里的规则二/三一致
- 上场时把别的蛇身体也算成墙，再加一层安全网：不许掉头、会把自己关死的位置直接重罚
- 所以它比豆包强（同样 10 秒能吃 8 个 vs 5 个），但也会失误，不是无敌

## 换对手

单人模式的入口在大厅，`#soloBot` 下拉框里选 豆包 / 派派，前端把 `{t:'solo', bot:'pai'|'doubao'}` 发给服务器，
服务器 `addBot(name, kind)` 记下 `botKind`，每一拍按 `botKind` 走不同的决策函数。
